
# Linux Commands and System Profile

## Objective
To understand Linux operating system commands and system information.

## Operating System
Ubuntu Linux

## Commands Executed

| Command | Purpose |
|---|---|
| whoami | Displays current username |
| hostname | Displays system hostname |
| pwd | Shows current directory |
| date | Displays date and time |
| uname -a | Shows system information |
| df -h | Displays disk space |
| free -h | Displays memory information |

## Conclusion
Linux commands help users understand and manage the operating system through the terminal.
